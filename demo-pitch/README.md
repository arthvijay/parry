# Parry pitch deck

Open `index.html` in Chrome (double-click it), press **F** for fullscreen, and use the arrow keys or a clicker.

| Key | Does |
| --- | --- |
| → / Space / clicker | Next slide |
| ← | Previous slide |
| F | Fullscreen |
| P | Presenter notes window (talking points + timer + next slide) |
| G | Jump to any slide |
| R | Replay the current slide's animation (handy on the live-date slide) |
| K | Play / pause the demo video |
| E | Media mode: outlines every photo/video slot so you can click or drop files |
| B | Black screen |
| M | Stamp "¡HUBO MATCH!" on the last slide |

## Add your demo video (slide 5)

Pick one:

1. **Drag the video file onto the big frame** (or click it). The deck remembers it in this browser, even after a reload.
2. Save it as `assets/demo.mp4`. It loads on its own and works on any laptop you copy the folder to.

MP4 (H.264) is the safest format. The video starts playing when you reach the slide.

Slide 13 also has a phone-shaped slot for a vertical clip (`assets/reel.mp4`). A screen recording of someone sharing their receipt works well there.
